## 二、阻断项（B 编号，附根因/证据/修复方案）

### B1 — `DELETE /api/v1/game-types/{id}` 未声明 response_model，触发契约测试失败 【✅ 已修复 2026-10-28】

- **证据**：`pytest tests/v1/test_api_contract.py::test_every_json_api_route_declares_response_model` 失败
  ```
  AssertionError: DELETE /api/v1/game-types/{game_type_id} must publish a response_model
  ```
- **根因**：`backend/app/foundation/router.py:123`
  ```python
  @router.delete("/game-types/{game_type_id}", status_code=204)   # 缺 response_model
  def delete_game_type(...):
  ```
  该路由是 `status_code=204`（无响应体），但守门测试要求所有 JSON 路由声明 `response_model`，而它既没声明、也未被 `NON_JSON_ROUTES` 豁免。
- **修复方案（二选一，推荐 A）**：
  - **A（推荐）**：把 `("DELETE", "/api/v1/game-types/{game_type_id}")` 加进 `tests/v1/test_api_contract.py:7` 的 `NON_JSON_ROUTES`——204 无响应体本就属"非 JSON 路由"，与现有豁免逻辑一致，零业务改动。
  - **B**：在路由上显式写 `response_model=None`（语义等价于 A，但会在 OpenAPI 留一个 None schema，不如 A 干净）。
- **影响**：该测试被 CI / 本地当作契约门禁，不修则套件恒红。

### B2 — 迁移 head 断言写死 `0010`，实际已到 `0024`，测试腐化 【✅ 已修复 2026-10-28，动态断言】

- **证据**：`pytest tests/v1/test_migration.py::test_current_migration_head_is_exposed` 失败
  ```
  assert '0024 (head)' == '0010 (head)'
  ```
  实跑 `alembic heads` → `0024 (head)`；仓库 `alembic/versions/` 实际有 **24 个迁移文件**，最新为 `0024_seed_game_type_channel_regions.py`。
- **根因**：`tests/v1/test_migration.py:203` 把 head 硬编码为字符串 `"0010 (head)"`。迁移链已从 0010 推进到 0024（新增 0011–0024 共 14 个），但断言未同步——典型"测试腐化"，**不是代码缺陷**，迁移本身正常。
- **修复方案（推荐 A）**：
  - **A（推荐）**：将断言改为动态读取当前 head（如 `_alembic({}, "heads").stdout.strip()` 再比对非空且唯一），彻底消除"加迁移必改断言"的维护债。
  - **B（最小改）**：把 `"0010 (head)"` 改成 `"0024 (head)"`，但下个迁移又要改，治标。
- **影响**：迁移相关 CI 恒红；同时提示本项目"记忆里写'迁移现至 0009'"已严重过时，真实状态是 0024。
