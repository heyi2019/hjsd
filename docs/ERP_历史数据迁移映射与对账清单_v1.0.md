# 黑金时代 ERP · 历史数据迁移映射与对账清单 v1.0

> **使用边界**：本文件是历史参考资料，只用于后续导入、对账与回归测试，不是首版开发的业务设计来源。遇到历史数据与 PRD/功能规格不一致时，保留历史原值并记录异常，不修改新单规则。

## 映射

| 原始表 | 新 ERP 目标 | 强制规则 |
|---|---|---|
| 个人记账明细 | cashflow / deposits | 每笔指定 pool；投资款→EXTERNAL_IN；可退押金入 deposits；介绍费/作图费为待关联 COST |
| 回款明细 | orders / order_events | 回收→HS、提号相关→TH、蹭点→DG、代分期→DFQ；历史 orders=UNLINKED |
| 回收账号登记 | accounts | 渠道拆 JSON；有二次→SECOND；手机号不作键 |
| 代分期订单登记 | installments | 无可靠订单/账号关联则 ORPHAN |
| 返点历史订单 | rebate_records | source_order_id=NULL、UNLINKED；不生成正式 REB 号 |
| 需求池 | leads | 空需求剔除；历史状态保留 |
