# ERP 领域治理阶段 0 裁决记录 v1.0

本文件记录领域治理启动时已经执行的结构性裁决，以及仍需业务负责人确认的事项。未确认事项在关闭前只能按临时口径实施，不得据此修改历史业务数据。

|---|---|---|---|

## 4. 执行纪律

1. 新需求若无法映射到一个主责域，先进入待确认裁决，不直接创建跨域共享写权限。
2. 任何影响订单、库存、流水、押金、返点或利润的变更，都必须引用本台账中的链路和指标口径。
3. 裁决状态从“待确认”变为“已确认”前，不得把临时口径写成不可逆的数据迁移。
4. 裁决发生变化时，必须同步更新领域归属台账、关键链路基线、核心指标口径表和测试验收项。
