## 三、关键修复与实测证据

### 3.1 UX 缺陷（P0 + 4 P1）
- **P0 白屏**：页面槽位包 `ErrorBoundary`，生产环境不暴露 `error.message`（`import.meta.env.DEV` 才回显），保留 `role=alert` + 重试。
- **P1 溢出**：`.page-content` / `.ant-table-wrapper` 加 `overflow-x` 约束，窄屏不再横向撑破。
- **P1 对比度**：`antdTheme.ts` 显式覆盖 placeholder/tertiary/quaternary/description/secondary 文本色，`colorLink` 由 `#0a84ff`（3.63）改为 `#0a63d8`（5.54），达 WCAG AA。
- **P1 导航状态**：`AppShell.tsx` 用 sessionStorage（`BIZ_TAB_KEY`）记忆业务中心 Tab，刷新不丢。
- **P1 触控目标**：`.ant-table-row-expand-icon` 提至 24px（提升特异性压 antd 运行时）。

### 3.2 测试提速（含 1 处真回归）
- 提速核心：Vitest 禁 `@ant-design/cssinjs` 样式注入（`aa3885a`），消除大缓存惩罚。
- 真回归：`3bf6f65` 将 `innerPage` 纳入 effect 依赖，内部翻页 `setInnerPage(2)` 被 `props.page(1)` 立即拉回 1，导致全量红。以 `useRef` 值比对替代（`156ddf0`），9/9 通过、全量 63s 绿。
- 基线：日常环 fast≈5s / quick≈10s（冷=热无差）；全量分片 63s 全绿（旧基线 710s 已过时 11×）。

### 3.3 E2E 真机联调基线
- 端口隔离：Vite 5180 / 后端 8124 + 独立库 `heijin_erp_e2e.db`，DEV 零登录。
- 全量 `50/50`（1.2min）可复跑。2 视觉快照失败经 diff 证实为 sidebar-foot 对比度修复导致的**良性基线过期**，已 `--update-snapshots` 重生成（`ccaccd7`）。
