## 4. 警告：0（一处已修复的鉴权缺口溯源记录）

首跑曾有 12 条 `PydanticJsonSchemaWarning`，**溯源后确认为真实鉴权缺口而非无害告警**，已修复并验证：

- **根因**：`app/options/router.py` 中 `_read_access = get_current_user`（裸函数，未包 `Depends()`）。FastAPI 不把裸函数默认值解析为依赖，`GET /option-sets(/{code})` 此前**匿名可访问**（实测无 token 返回 200）；写端点因 `require_permissions(...)` 返回 `Depends` 实例而正常 401。
- **修复**：`_read_access = Depends(get_current_user)`（提交 `d48f8fa`）。
- **验证**：无 token GET → 401；全量 warnings 归零；新增 `test_read_requires_login` 回归守卫；前端 axios 统一带 Bearer token，不受影响。

## 5. 测试提速收口（212s → 48.2s，4.4x）

`backend/tests/v1/conftest.py` 三项改造，用例语义不变（提交 `4e57b9a`）：

| 改造 | 根因 / 依据 | 收益 |
| --- | --- | ---: |
| `app` 夹具 session 级复用 | `create_app()` 单次实测 414.6ms（162 条路由注册纯 CPU），函数级重建曾为最大开销 | ~省 60s+ |
| `seeded_db` 种子模板 ATTACH 回放 | `seed_foundation` 单次 40–95ms × 978 条种子用例；改为会话级 seed 一次，每用例 `INSERT..SELECT` 依赖序回放（纯 SQL 层，几 ms） | 省 ~38s CPU |
| 测试引擎 PRAGMA `synchronous=OFF` / `journal=MEMORY` | 测试库无需崩溃安全，仅作用于测试引擎，不碰生产 `database.py` | 小幅 |

**xdist 并行实测被否**：loadfile 61.7s / load 56.6s，均慢于串行 48.2s——套件变轻后 8 worker 的导入开销超过并行收益；**本套件保持串行**，勿加 `-n` addopts。剩余 48s 以路由调度与业务逻辑为主，清库仅 ~1.4s，继续压榨 ROI 低。
