## 问题记录

### P1：生产售出表单缺少“全款/分期付款”选项（已修源码，待发布复测）

回收/提号售出弹窗只显示“付款方式”标题，没有“全款”和“分期付款”单选项。源码组件已具备分期分支，但生产 `SALEREC`、`SALETH` 字段配置的 `payment_method.options` 为空；本地测试夹具带有选项，因此本地未暴露。

已处理：

- `catalog_seed` 对空配置补齐全款/分期选项；
- 新增迁移 `0078_backfill_sale_payment_method_options`，修复已有数据库；
- 增加后端种子回归和前端选项可见性测试。

### P1：部分收款没有进入分期链路

提号 `TH0038` 出售时录入了“分期首款”600 元和资金流水备注，但线上仍直接显示“已售/已完成”，分期与回款页面仍为 0 个合约、0 应收。订单台账显示金额 `1500.00`，与实际输入的首款金额不一致。

这说明当前线上版本无法通过真人 UI 完成提号分期出售，且存在金额口径/提交值不一致风险。修复 P1 的付款方式配置后必须重新用“付款方式=分期付款、首付、期数、每期金额、日期”完整复测；在复测通过前，不应宣称分期出售可用。

### P1：账号台账与库存中心编辑入口不一致

库存中心行级“编辑”按钮显示为禁用；订单台账的“编辑订单”可以修改备注。两者都指向同一账号/订单，但编辑范围和交互不一致，容易让用户误以为库存中心不可编辑或编辑已失效。建议统一为同一套账号编辑能力，并明确订单字段与账号字段的边界。

### P2：提号供货方来源的默认值不稳定

第一笔提号表单显示“自营”并可直接创建；第二笔表单未选供货方来源，提交时提示“请选择供货方来源”，补选“自营”后才成功。需要统一默认值策略，或始终明确要求用户选择。
