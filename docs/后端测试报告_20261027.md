## 4. 警告（已定位并修复）

12 条 warnings 全部为同一来源：`PydanticJsonSchemaWarning`（`get_current_user` 函数对象作为参数默认值进入 JSON schema）。**溯源结论：不是无害告警，而是一处真实鉴权缺口。**

- **根因**：`app/options/router.py` 中 `_read_access = get_current_user`（裸函数，未包 `Depends()`）。FastAPI 不会把裸函数默认值解析为依赖，端点收到的 `user` 是函数对象本身（代码 `del user` 丢弃才未崩溃），**`GET /option-sets` 与 `GET /option-sets/{code}` 此前匿名可访问（实测无 token 返回 200）**。写端点因 `require_permissions(...)` 返回 `Depends` 实例而正常拦截（401）。
- **修复**：`_read_access = Depends(get_current_user)`（1 行）。
- **验证**：无 token GET → 401；OpenAPI 生成 warnings 归零；`test_option_sets_api.py` 补 5 处匿名 GET 鉴权并新增 `test_read_requires_login` 回归守卫后 12 passed；`test_api_contract.py` 复跑通过。前端 axios 统一带 Bearer token，不受影响。
