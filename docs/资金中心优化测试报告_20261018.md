## 4. 已新增的关键用例

- 押金明细展示 `counterparty_id`、`source_order_id`、`expected_release_on`。
- 按流水号关键词筛选后，仅显示匹配流水，统计同步收敛。
- 对账记录打开未达流水弹窗，并显示关联流水。
- 资金流水筛选区使用紧凑宽度：关键词较宽，枚举筛选项按语义宽度收敛，日期筛选自动换行。
- 筛选区与下方统计卡片增加清晰的垂直间距，避免视觉粘连。
